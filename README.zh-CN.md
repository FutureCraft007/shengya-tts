# 声芽配音 · Shengya TTS

[English](README.md)

声芽配音是一款面向 Android 和 Windows 的文字配音工具，可用于短视频旁白、教程解说、有声内容和应用提示音。项目基于 Danmoreng 的 [qwen3-tts-android](https://github.com/Danmoreng/qwen3-tts-android) 二次开发，使用 [qwen3-tts.cpp](https://github.com/Danmoreng/qwen3-tts.cpp) 和 GGML 进行本地推理。

## 离线配音模型

模型可在应用内下载或导入，准备好后即可离线生成语音。两端都可以在配音工作台切换模型。

| 模型 | 能做什么 | 适合什么场景 |
| --- | --- | --- |
| **Qwen3-TTS Base** | 导入参考录音，创建可重复使用的本地音色 | 用自己的声音配音，或复用已获授权的音色 |
| **Qwen3-TTS CustomVoice** | 选择模型提供的预置音色，输入文字直接生成 | 视频旁白、教程解说 |
| **Kokoro** | 提供 100 个中文音色和 3 个英文音色，可调语速 | 日常中文配音、短文朗读 |
| **Paradee** | 英文模型约 8.46 MB，提供一个英文女声，可调语速 | 英文短句、提示音、轻量朗读 |

## 从文案到成品

1. **选模型和音色。** 在配音工作台选好模型，再从预置音色或本地音色库中选择声音。
2. **输入文案并生成。** 使用支持语速调整的模型时，可以先用短句试听，再生成整段文案。
3. **试听并导出。** 本地生成的音频会保存在历史记录里，可回听并导出为 WAV，用于剪辑或其他音频工作。

## 本地音色克隆

使用 Qwen3-TTS Base，从音色库导入 **3～30 秒**的清晰单人录音。可以填写与录音完全对应的逐字稿，启用完整克隆模式。创建后的音色保存在本地音色库，之后可以用它朗读新的文案。参考录音可使用自己的声音，或使用已获授权的声音。

## 自定义云端配音

Android 和 Windows 都可以接入用户自己的语音合成服务。填写**完整 HTTPS 接口地址、API Key、模型和音色 ID**，即可在云端页面输入文案、生成并试听。服务需兼容 OpenAI 的 `/audio/speech` 请求格式，并直接返回 WAV。

## Android 特色功能

- **本机降噪**：在历史记录中使用 RNNoise 处理生成的音频，可分别试听和导出原声与降噪版。
- **本机配音接口**：手动启动服务后，同一台手机上的其他应用可以提交配音任务并获取结果，支持配置 1～6 路推理。
